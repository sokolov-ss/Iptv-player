# IPTV Player (Web Prototype)

Простой веб-плеер IPTV с поддержкой M3U/M3U8 плейлистов.

## Возможности
- Добавление плейлиста по ссылке
- Парсинг M3U
- Поиск каналов
- Воспроизведение HLS-потоков
- Работает на ПК, Android и iPhone (Safari)

## Как открыть
Просто откройте `index.html` в браузере или используйте GitHub Pages.
